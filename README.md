# CamShare

CamShare is a small browser-based project for sharing and recording a laptop screen. The project is being built in stages, starting with screen recording and progressing toward connecting a phone camera, combining media, and eventually live streaming.

## Project roadmap

### المرحلة 1 — تسجيل الشاشة

نعمل تطبيقًا بسيطًا يعرض شاشة اللابتوب ويسجلها في ملف فيديو.

**نبدأ هنا — هذه هي المرحلة الحالية.**

### المرحلة 2 — كاميرا الهاتف

نعرض فيديو كاميرا الموبايل على اللابتوب.

### المرحلة 3 — الاتصال المباشر

نربط الجهازين باستخدام WebRTC ونتعلم كيفية التعامل مع تأخير الاتصال.

### المرحلة 4 — التسجيل والتركيب

ندمج الشاشة والكاميرا والصوت في تسجيل واحد، مع إمكانية الاحتفاظ بالمسارات منفصلة.

### المرحلة 5 — البث المباشر

نضيف البث المباشر بعد التأكد من أن التسجيل يعمل بشكل جيد.

## المرحلة الحالية

التطبيق عبارة عن صفحة واحدة في [`index.html`](./index.html)، وتتيح لك:

- اختيار شاشة أو نافذة أو علامة تبويب لمشاركتها من نافذة المتصفح.
- مشاهدة معاينة مباشرة أثناء التسجيل.
- إيقاف التسجيل يدويًا أو عند إيقاف مشاركة الشاشة.
- مشاهدة التسجيل الناتج وتنزيله بصيغة WebM.

التسجيل الحالي يلتقط الفيديو فقط، من دون صوت. تتم المعالجة داخل المتصفح، ولا يرفع التطبيق التسجيل إلى خادم.

## التشغيل

يحتاج المتصفح إلى صلاحية مشاركة الشاشة، كما يجب تشغيل الصفحة ضمن سياق آمن. يمكنك استخدام خادم محلي للتطوير:

1. افتح موجّه الأوامر داخل مجلد المشروع.
2. شغّل:

   ```bash
   python -m http.server 8000
   ```

3. افتح [http://localhost:8000](http://localhost:8000) في متصفح يدعم مشاركة الشاشة وتسجيل الوسائط، مثل إصدار حديث من Chrome أو Edge أو Firefox.
4. اضغط **Start recording**، واختر الشاشة أو النافذة أو علامة التبويب، ثم وافق على المشاركة.
5. اضغط **Stop recording** عند الانتهاء، ثم عاين الفيديو أو نزّله.

يمكن أيضًا فتح `index.html` مباشرةً إذا كان المتصفح يسمح بمشاركة الشاشة في هذا السياق. عند تعذّر ذلك، استخدم عنوان `localhost` كما في الخطوات أعلاه.

## التقنيات الحالية

- HTML وCSS وJavaScript بدون إطار عمل.
- `getDisplayMedia` لطلب مشاركة الشاشة.
- `MediaRecorder` لتسجيل الفيديو محليًا في المتصفح.

## ملاحظات

- يجب أن يبدأ طلب مشاركة الشاشة من تفاعل مباشر مع المستخدم، مثل الضغط على زر التسجيل.
- خيارات مشاركة الشاشة والصيغ المدعومة تعتمد على المتصفح ونظام التشغيل.
- التسجيلات الحالية بصيغة WebM، ولا يشمل التسجيل الصوت.
- المشروع في مرحلته الأولى؛ لا يتضمن حاليًا اتصالًا بكاميرا هاتف أو WebRTC أو بثًا مباشرًا.
